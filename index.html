Dashboard Jadwal Rapat dan Kegiatan

Tempel teks undangan rapat/kegiatan, klik Tambahkan ke Jadwal, lalu sistem akan membuat resume tabel dan kalender agenda secara otomatis. Data tersimpan di browser melalui localStorage dan akan tetap terakumulasi ketika halaman dibuka kembali.

0. Konfigurasi Database Online Google Sheet

Untuk mode online GitHub Pages + Google Sheet, isi URL Web App Google Apps Script dan Token Akses. Setelah tersambung, data jadwal akan dibaca/ditulis ke Google Sheet. Bila belum diisi, dashboard tetap berjalan dengan penyimpanan lokal browser.

Mode lokal / belum tersambung

1. Input Teks Undangan

Paste isi undangan pada kotak di bawah. Sistem akan mengenali pola Hari/Tanggal, Waktu, Agenda, Tempat, dan Catatan/Keterangan.

2. Preview dan Koreksi Data

Hasil baca otomatis dapat dikoreksi manual sebelum ditambahkan atau disimpan kembali.
